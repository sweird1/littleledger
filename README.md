# LittleLedger 小账本

iPhone 优先的 AI 记账 App（React Native + Expo + TypeScript）。

- 中文：小账本 ｜ 英文：LittleLedger
- AI：阿里云百炼 千问——自然语言一句话记账（经服务端网关，Key 不进客户端）
- 存储：expo-sqlite，同步就绪 schema

📄 **完整计划（定位/架构/数据模型/商业化/路线图）见 [docs/PLAN.md](docs/PLAN.md)**

## 开发（Windows 即可）

```bash
npm install
npm start        # 手机装 Expo Go，扫码即调
```
